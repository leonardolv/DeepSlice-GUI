DeepSlice GUI Help

Use this page with F1 context help in the app.

Global 1. Add images 2. Settings 3. Run alignment 4. Review & fix 5. Export

Global Shortcuts

  • Ctrl+1..Ctrl+5: jump to workflow steps; Alt+Right / Alt+Left: next / previous step
  • Ctrl+N: start a new session
  • Ctrl+S: save session
  • Ctrl+O: load session or QuickNII file
  • Ctrl+/: open shortcut cheat sheet
  • F1: open this help page for the current step

Step 1: Add images

  • Follow the blue guidance banner at the top of each step; its Next button unlocks the next step.
  • Add files/folders, drag and drop, or click the drop area to browse (Enter/Space also work when it is focused).
  • Use naming helper for _sXXX index parsing.
  • Use sorting/filter to inspect large sets quickly.
  • Check the index table for duplicates and parse warnings. The summary bar turns amber when there are warnings.
  • On a small screen the window can be shrunk to about 960 x 600; pages scroll and the top bar switches to icon-only buttons (hover for names).

Step 2: Settings

  • Select species and review atlas preview card.
  • Set thickness manually or auto-estimate.
  • Advanced options (prediction modes, quality, preprocessing, training) are collapsed by default; the defaults suit most data.
  • Use Validate Configuration before prediction.
  • Read ensemble help for speed vs stability tradeoff.

Step 3: Run alignment

  • Run Alignment to start inference.
  • Use Cancel Alignment to stop at a safe batch boundary.
  • The bold sentence under the buttons says in plain words what is happening (for example "Predicting: section 2 of 5").
  • Monitor stage, sections done, elapsed time, and ETA.
  • Use "Show detailed log" (with Copy/Clear) for troubleshooting.
  • If a run fails the message gives the reason in one line plus what to try; the full traceback is under Show Details.

Step 4: Review & fix

  • The left column is split into numbered groups: 1. Mark sections that look wrong, 2. Order and notes, 3. Fix angles and spacing, 4. Anchor known sections (optional). The filled blue button is the main action of each group; outlined buttons are secondary; the red-outlined one (Reset All Flags) is destructive.
  • Shortcuts shown on the buttons: K / J previous / next section, F flag or unflag, A / D set / remove anchor, Ctrl+Enter apply flags.
  • Review confidence colors and linearity plot.
  • Use context menu or space key to toggle bad flags.
  • Atlas overlay controls are in the "Atlas overlay" box; flip / rotate / scale / offset are behind "Adjust atlas position and size".
  • Use Undo/Redo and the Show filter for targeted edits.

Step 5: Export

  • Choose output format and base filename.
  • Export writes primary format plus CSV sidecar.
  • After exporting, the files that were written are listed under the buttons; use Open folder / Copy path for downstream workflows.
  • "Fine-tune in QuickNII" is optional: pick the QuickNII program once (a status line says whether it was found); "Open in QuickNII" unlocks after a JSON export and opens that file.
  • Generate or preview PDF report with selectable sections.
