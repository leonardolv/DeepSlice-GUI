DeepSlice GUI Help

Use this page with F1 context help in the app. For a guided walkthrough with examples, see the full tutorial.

Global Shortcuts

  • Ctrl+1..Ctrl+5: jump to workflow steps (locked steps stay locked)
  • Ctrl+E: jump to Export
  • Ctrl+N: start a new session
  • Ctrl+S: save session
  • Ctrl+O: load session or QuickNII file
  • Ctrl+,: open Preferences
  • Ctrl+/ (or Ctrl+?): open shortcut cheat sheet
  • F1: open this help page for the current step
  • Review & fix page only: J / K next / previous section, F toggle bad flag, A / D set / remove anchor, Ctrl+Enter apply bad-section flags, Ctrl+Z / Ctrl+Y undo / redo, Ctrl++ / Ctrl+- / Ctrl+0 zoom the linearity plot

Step 1: Add images

  • Follow the blue guidance banner at the top of each step; its Next button unlocks the next step.
  • Click Add Folder or Add Files, or drag and drop onto the drop area. Clear All removes every image. Accepted: JPG, JPEG, PNG, TIF, TIFF.
  • Keep "Read section numbers from filenames (e.g. _s012)" ticked; the ? button explains naming (brain1_s001.png is section 1). Use "Older naming" only for files without _sXXX.
  • Cutting plane must be Coronal (supported).
  • Use the Sort and "Filter by filename..." controls to inspect large sets; double-click a thumbnail for a fullscreen preview, right-click to copy its path or remove it.
  • Check the index table (Filename, Detected Index, Status): every row should say OK. Duplicate means two files share a section number and blocks the run.

Step 2: Settings

  • Select Mouse (Allen CCFv3) or Rat (Waxholm Rat Atlas) under Species / Atlas.
  • Physical Geometry: keep "Auto-estimate thickness" or untick it and enter Section Thickness (um). Direction Override only if you need to override the detected direction.
  • Advanced options (Prediction Modes, Quality and Runtime, Preprocessing and Inference, Training Toolkit) are collapsed by default; the defaults suit most data.
  • "Enable input quality gate" (Preprocessing and Inference, on by default) scans your images when you press Run Alignment. Tune it with Min resolution (px) and Blur threshold.
  • Use Validate Configuration before prediction; the Validation line names anything that still blocks Run Alignment.
  • Read the ensemble ? help for the speed vs stability tradeoff.

Step 3: Run alignment

  • Run Alignment starts the job. If the quality gate is on, the button first reads "Scanning inputs..." while every image is checked.
  • A "Quality Gate Warning" lists resolution mismatches, flagged images (low resolution, blurry, underexposed, overexposed, saturated, artifact) and unreadable files. Choose Yes to continue or No to go back and fix them.
  • Use Cancel Alignment to stop at a safe batch boundary.
  • Monitor Phase, Progress, Elapsed and Remaining.
  • Show Runtime Console reveals logs with Auto-scroll, Clear and Copy buttons.
  • After completion, Use Predicted Thickness copies the estimate into Settings.

Step 4: Review & fix

  • Review confidence colors and the linearity plot; the Filter box offers All Confidences, High Only, Medium Only, Low Only and Review Queue.
  • Toggle bad flags with the checkbox, the F or Space key, Toggle Current, or the right-click menu, then click Apply Bad Section Flags.
  • Detect Outliers, Auto-Flag Low Confidence and Interpolate Flagged Depths suggest and repair flagged sections.
  • In Propagation / Curation use Normalize Angles, then Enforce Index Order, then Enforce Index Spacing. Apply Manual Angles overrides ML/DV.
  • Anchor Alignment: Set/Update Anchor, then Distribute Between Anchors (needs at least two anchors).
  • Undo (n) / Redo (n) buttons snapshot every curation action.

Step 5: Export

  • Browse for the Output Directory, set Base Filename, and choose JSON (QuickNII/VisuAlign) or Legacy XML.
  • Export Predictions writes the chosen format plus a CSV sidecar; you are asked to confirm if any section has confidence below 0.50.
  • Open Folder / Copy Path help locate the files.
  • Preview Report and Generate Report (PDF) use the PDF Contents checkboxes and need the reportlab package.
  • Open in QuickNII needs a JSON export from this session; set the QuickNII path first if prompted.
