DeepSlice Desktop - Professional Tutorial

This guide mirrors the app and tells you what to click, where to click it, and why. Follow it end-to-end to go from raw histology images to curated QuickNII-compatible outputs and reproducible reports. In a hurry? The Quick Start below gets a first result in ten steps.

Quick Start + 11 Lessons Beginner to Advanced ~45-60 min
Beginner

Quick Start - Your First Alignment in 10 Steps

Example dataset used throughout this guide: a folder Mouse12/ holding 45 coronal sections named Mouse12_s001.tif to Mouse12_s045.tif. Substitute your own folder.

1

Start the app

Run deepslice-gui in a terminal (see Installation if the command is not found).

2

Step 1 - Add images

Drag the Mouse12 folder onto the drop area, or click Add Folder.

3

Check the index table

Every row of the table should show a number in Detected Index (1 to 45) and OK in Status. The banner reads "45 files - 45 valid indices - 0 warnings".

4

Step 2 - Settings

Click Next: Settings (or press Ctrl+2), pick Mouse (Allen CCFv3) and leave everything else at its default.

5

Step 3 - Run alignment

Click Next: Run alignment, then Run Alignment. The button briefly reads "Scanning inputs..." while the input quality gate checks your images. If a "Quality Gate Warning" appears, read it, then choose Yes (continue) or No (go fix the images).

6

Wait for the progress bar

You can watch Phase, Progress, Elapsed and Remaining. A CPU run can take several minutes.

7

Step 4 - Review & fix

Click Next: Review & fix. Click Detect Outliers, then Normalize Angles. Press J / K to step through sections and compare each with the atlas. Not happy with a change? Click Undo.

8

Step 5 - Export

Press Ctrl+E. Click Browse to choose an Output Directory, keep JSON (QuickNII/VisuAlign), then click Export Predictions. You get DeepSliceResults.json and DeepSliceResults.csv.

9

Save the session

Press Ctrl+S and save a .deepslice-session.json file so you can resume later.

10

Open the result in QuickNII

Click Open in QuickNII (set the QuickNII path first if prompted), or load the JSON in QuickNII / VisuAlign yourself.

✓ Outcome

You have an exported alignment plus a resumable session. The lessons below explain each step in depth.

Beginner

Lesson 0 - Prerequisites

  • A 64-bit computer that can install TensorFlow and PySide6 (Windows 10/11 is the main target)
  • Python 3.9 to 3.12 in a virtual environment (3.11 or 3.12 recommended)
  • At least 8 GB RAM (16 GB+ recommended for larger datasets)
  • Histology images in .jpg, .jpeg, .png, .tif, or .tiff (other file types are listed as "Unsupported files excluded")
  • File naming with section IDs (recommended): _s001, _s002, ...
  • Optional: QuickNII installed, if you want one-click opening of results
Important: The current desktop release supports coronal sections in the main workflow. Sagittal and horizontal appear in the Cutting plane list as "coming soon" and will block Run Alignment if selected.
Beginner

Lesson 1 - Installation

Set up a clean environment and install DeepSlice together with its GUI dependencies. The installer pins a TensorFlow version known to work with DeepSlice, so you normally do not install TensorFlow by hand.

1

Open a terminal in the repository folder

cd path\to\DeepSlice-GUI

On macOS/Linux use forward slashes. Use the folder that contains setup.py.

2

Create and activate a virtual environment

python -m venv .venv
.venv\Scripts\activate

On macOS/Linux: source .venv/bin/activate.

3

Install the project with all optional features

python -m pip install --upgrade pip
python -m pip install -e ".[all]"

This installs TensorFlow, scikit-image and PySide6, plus two optional extras: reportlab (needed for Generate Report (PDF)) and nibabel (needed for the atlas volume preview). Plain python -m pip install -e . works too; the PDF report and atlas preview then ask you to install the missing package when first used.

4

Optional: verify TensorFlow imports

python -c "import tensorflow as tf; print(tf.__version__)"

Expect a 2.x version (2.13 to 2.15 on Python 3.9-3.11, 2.16 on Python 3.12).

Do not run pip install "tensorflow<3.0" on top of this. It can replace the pinned TensorFlow with a newer one that DeepSlice has not been tested with. If you do see ModuleNotFoundError: tensorflow or skimage, re-run step 3, or use Errors > Try Auto-Fix Last Error (Lesson 10).
GPU note: TensorFlow on native Windows generally runs CPU-only for newer versions. This is normal; DeepSlice still runs correctly on CPU, just more slowly.

✓ Outcome

The runtime environment is ready and the deepslice-gui command exists in your virtual environment.

Lesson 2 - First Launch & Health Check

1

Launch the GUI

deepslice-gui

Equivalent alternatives: python -m DeepSlice.gui.app or python DeepSlice/main.py. Wait for the DeepSlice Desktop window to appear.

2

Read the first-run walkthrough

On the very first launch a short "Welcome to DeepSlice" dialog lists the five steps. After an upgrade a "What's new" dialog may follow. Click OK to dismiss each.

3

Click Hardware Health in the top bar

The dialog lists Mode (CPU or GPU), TensorFlow, CUDA and cuDNN versions and detected GPUs. The label next to it, Runs on: CPU or Runs on: GPU, updates too.

4

Confirm error tooling is available

The top bar has an Errors menu containing Open Error Log, Copy Last Error and Try Auto-Fix Last Error. The last two stay greyed out until an error has occurred.

✓ Outcome

You confirmed the app launches and the runtime diagnostics controls are visible.

Lesson 3 - UI Orientation

The window has a step list on the left and the current step's page on the right. Workflow order is intentional: later steps stay locked until their inputs exist.

Step Navigator

1. Add images -> 2. Settings -> 3. Run alignment -> 4. Review & fix -> 5. Export. Steps 2 and 3 unlock once at least one image is loaded; steps 4 and 5 unlock after the alignment has run. Hover a locked step to see what unlocks it. The percentage above the list shows overall completion and the << button collapses the list.

Guidance Banner

The blue banner above every page says "Step N of 5", what to do, a live status line (for example "45 images loaded") and a Next: ... button that is enabled as soon as the next step is unlocked.

Top Bar

Project name, Session: status, Runs on: CPU/GPU, then the buttons Theme (Dark/Light), Hardware Health, New Session, Save Session, Load Session / QuickNII, Shortcuts, Preferences, About and Errors. On narrow windows the buttons wrap to a second row.

Step Markers

In the step list ✓ means completed, ● current, ◌ locked.

Runtime Console

On the Run alignment page, Show Runtime Console reveals live logs with Auto-scroll, Clear and Copy. Use it when running alignment or debugging.

Help

Press F1 to open the help page at the section for the step you are on, or Ctrl+/ for the shortcut sheet. Hover any control for a tooltip.

Workflow rule: If Run Alignment is disabled, the orange line right under the button (and the button tooltip) names what is blocking it, for example "No images loaded" or "Duplicate section numbers are not allowed".
Beginner

Lesson 4 - Step 1: Add Images

1

Open "1. Add images"

A new session opens here by default. Anywhere else, press Ctrl+1.

2

Add your images

Drag a folder or files onto the drop area ("Drag and Drop Images or Folders"; folder drops recurse into subfolders), or click Add Folder / Add Files. Clear All removes every loaded image. You can also drop files onto the thumbnail grid.

3

Check the filename and orientation options

In the Filename and orientation box, leave Read section numbers from filenames (e.g. _s012) ticked for indexed workflows. Tick Older naming: use the last 3 digits of the filename only if your files do not use _sXXX; it takes the last three digits found anywhere in the name. Cutting plane must stay on "Coronal (supported)". The ? and Guide buttons open short explanations.

Naming examples: brain1_s001.png is section 1; mouse_A_s142_fluoro.tif is section 142. With the older option, slide_A_017.tif is read as 17. Each filename may contain _s followed by digits only once: run_s2_brain_s010.tif is rejected as ambiguous, and one bad filename marks every row as a Parse Error until fixed.
4

Review the index table

The table has three columns: Filename, Detected Index, Status. OK is good. A red Duplicate row means two files share one section number; a Parse Error means no number could be read. The banner above the table summarises the count, valid indices and warnings, and the orange text lists duplicates, missing indices and unsupported files.

Example problem: ratA_s010.tif and ratA_s010_copy.tif both map to index 10, so both rows turn red and Run Alignment reports "Duplicate section numbers are not allowed". Remove or rename one file (right-click a thumbnail > Remove this image).
5

Thumbnail QA

Use Sort: (Filename, Detected Index, Modified Date) and Filter by filename... to inspect large sets. Click a thumbnail to preview it, double-click for a fullscreen preview, or right-click for Preview Fullscreen, Copy Image Path and Remove this image. Look for sections that are flipped, wrongly rotated or blank before inference.

✓ Outcome

The dataset is loaded, each file has a unique valid section number, and you can click Next: Settings.

Beginner

Lesson 5 - Step 2: Settings

1

Select species

In Species / Atlas choose Mouse (Allen CCFv3) or Rat (Waxholm Rat Atlas). This selects the model and atlas. Rat support is labelled beta in the project README.

2

Set physical geometry

In Physical Geometry, leave Auto-estimate thickness ticked for a first pass. To enter a value yourself, untick it and type Section Thickness in um (typical range 20-100 um). Suggest Thickness works after predictions exist and fills in an estimate for you. Detected direction shows what DeepSlice inferred; use Direction Override (Auto, rostro-caudal, caudal-rostro) only to deliberately override it. The Guide button explains the options.

Example: DeepSlice multiplies the difference between section numbers by the thickness. You cut 40 um sections and your files keep the original numbers (_s004, _s008, _s012 for every 4th section): enter 40. If you renumbered the kept sections 1, 2, 3 instead, enter the real distance between neighbours, 160 um.
3

Open Advanced options only if needed

Click Advanced options (optional - defaults work for most data) to expand four groups:

  • Prediction Modes: Ensemble prediction (if available) (on by default, slower but often more stable; the ? button explains it), Use secondary model only (for comparison) (do not combine with ensemble) and Legacy section-number parser.
  • Quality and Runtime: Outlier sensitivity (sigma), High confidence >=, Medium confidence >= and Inference batch size.
  • Preprocessing and Inference: Enable input quality gate (see Lesson 6), Tissue ROI crop, CLAHE contrast normalization, Stain normalization, Min resolution (px), Blur threshold, Test-time augmentation (flip), Multi-scale inference, Fast mode (float16 inputs) and more.
  • Training Toolkit: dataset split and training metadata for fine-tuning; not needed for alignment.
4

Validate

The panel shows Will process N slices and an estimated processing time. Click Validate Configuration for a summary. The Validation: line at the bottom reads "ready" or names what still blocks Run Alignment.

Technical Insights (right side, collapsed) explains how angles and thickness are estimated.

✓ Outcome

Configuration shows "Validation: ready" and you are set to run the prediction.

Beginner

Lesson 6 - Step 3: Run Alignment

1

Click Run Alignment

Do this once the orange blocker line is gone. Possible prompts, in order:

  • Re-run Alignment - appears only if you already curated a previous result; continuing discards those edits.
  • Proceed With Warnings - for non-blocking issues such as fewer than 10 slices.
  • Quality Gate Warning - see the next step.
2

Understand the input quality gate

The quality gate is a pre-flight scan that reads each image before the model runs so you find problems in minutes, not after a long run. It is controlled by Settings > Advanced options > Preprocessing and Inference > Enable input quality gate and is on by default.

  • While it scans, the button reads Scanning inputs... and is disabled. The scan runs in the background, so the window stays responsive.
  • It checks for: images of different sizes (resolution mismatch), and per-image flags low resolution, blurry, underexposed, overexposed, saturated and artifact, plus files that cannot be read at all.
  • Nothing flagged: prediction starts immediately.
  • Something flagged: a Quality Gate Warning dialog lists the findings and asks "Continue with prediction?". The default answer is No.
  • The thresholds are tunable in the same group: an image is "low resolution" when its shorter side is below Min resolution (px) (default 500), and "blurry" when its sharpness (Laplacian variance) is below Blur threshold (default 0.0002). Lower either value if the defaults are too strict for your microscope.
  • If the scan itself fails you see "Input Quality Scan Failed", then "Skip Quality Gate" asking whether to continue without it.
  • Untick the checkbox to skip the scan entirely and start prediction directly.
Example dialog: "Input resolution mismatch detected (4000x3000, 2000x1500)", "Quality gate flags: low resolution: 1, blurry: 3" and "2 image(s) could not be read and will likely fail during prediction (s017.tif, s018.tif)". Click No, go back to step 1, remove or re-export those files, then run again. Click Yes only if you accept the risk, for example a few slightly blurry sections you will review later.
The gate only reports; it never edits or deletes your files.
3

Monitor runtime phase and progress

Read Phase (for example "Phase 1/3"; 3 phases with ensemble, 2 without), Progress, Elapsed, Remaining and the progress bar. The window title shows the running percentage. Use Cancel Alignment to stop at the next safe batch boundary; if only the secondary pass failed, DeepSlice may offer to keep the partial result.

4

Open the runtime console when needed

Click Show Runtime Console for detailed logs. Copy puts the whole log on the clipboard, handy for bug reports.

5

Check the results panel

After completion you see Estimated thickness and Detected indexing direction. Click Use Predicted Thickness to copy the estimate into Settings (it unticks Auto-estimate thickness and sets the value).

6

Preview per-slice alignment vectors

Use the slice selector (rows look like "12 | Mouse12_s012.tif") to see the O/U/V plane vectors, the matching atlas section and the model-input preview. Check a few sections from the start, middle and end.

✓ Outcome

Predictions are generated, the indexing direction is detected, and steps 4 and 5 are unlocked.

Intermediate

Lesson 7 - Step 4: Review & Fix

Use this stage to improve geometric consistency and exclude unreliable sections before export. Single-key shortcuts (J, K, F, A, D) only work on this page.

1

Get oriented

The left list shows every section with a checkbox; a ticked box means "flagged bad". Move with Prev / Next or K / J, or click a point on the linearity plot to jump to that section. Narrow the list with Filter: All Confidences, High Only, Medium Only, Low Only, or Review Queue (the sections most worth inspecting; the count is shown as "Review queue: N slices"). Plot buttons Fit, +, - zoom the plot.

2

Flag problematic sections

Tick a row's checkbox, press F (or Space in the list), click Toggle Current, or right-click > Flag as Bad. Select All / Deselect All act on every row. Then click Apply Bad Section Flags (Ctrl+Enter) so the flagged sections are excluded from the alignment calculations; ticking alone changes nothing until you apply.

3

Let the app suggest flags (recommended baseline)

  • Detect Outliers marks sections that deviate statistically in angle or spacing (strictness set by Outlier sensitivity in Settings).
  • Auto-Flag Low Confidence also flags sections below your Medium confidence threshold and high-risk ones.
  • Interpolate Flagged Depths then fills the AP depth of flagged sections from confident neighbours (gaps up to 6 sections).
  • Reset All Flags clears the ticks again.
4

Apply geometric refinements in this order

In the Propagation / Curation group:

  1. Normalize Angles - brings the cutting angles of all sections to a common value (a warning toast appears if it did not fully converge).
  2. Enforce Index Order - makes the depth order match the section numbers.
  3. Enforce Index Spacing - makes the spacing even, using your Settings thickness (or the auto estimate).

Use this sequence when section numbering is trustworthy and you want stable serial geometry.

5

Manual angle override only when justified

Enter ML Angle and DV Angle in degrees and click Apply Manual Angles only when you have an explicit reason to override the inferred mean.

6

Fix the order by hand

If files were numbered wrongly, drag rows in the list, or select a row and use Move Up / Move Down, then click Apply Manual Reordering.

7

Pin known sections with anchors

In Anchor Alignment: select a section, type its known Target AP depth, click Set/Update Anchor (A). Remove Anchor (D) and Clear undo anchors. With at least two anchors, Distribute Between Anchors spreads the remaining depths between them.

Example: Section 1 sits at the olfactory bulb and section 45 at the cerebellum, and you know both depths. Anchor both, then click Distribute Between Anchors.
8

Use the atlas preview for sanity checks

Tick Atlas volume preview, choose a Volume, optionally tick Blend atlas on histology and move the slider (5-95%). Before/After Overlay compares raw predictions with your curation; Loupe magnifies under the pointer. Flip X, Flip Y, Rotate, Scale and Offset adjust the atlas display only. The first use downloads the atlas volumes and needs the nibabel package.

9

Annotate and undo freely

Type a remark in the note field and click Save Slice Note. Every curation action is snapshotted: Undo (n) (Ctrl+Z) and Redo (n) (Ctrl+Y) show how many steps are available.

✓ Outcome

You have a curated, internally consistent dataset ready for publication/export pipelines.

Lesson 8 - Step 5: Export

1

Set output destination

In Export Configuration, click Browse next to Output Directory (the choice is remembered), then set Base Filename (default DeepSliceResults).

2

Select the primary export format

OptionWhen to use
JSON (QuickNII/VisuAlign)Default for modern workflows and marker preservation. Required for Open in QuickNII.
Legacy XMLUse only for older downstream tooling.
3

Click Export Predictions

This writes <base>.json (or .xml) plus an automatic <base>.csv sidecar. If any section has confidence below 0.50 you are asked "Export anyway?". Afterwards Open Folder and Copy Path help you find the files. Example result: D:\results\DeepSliceResults.json and D:\results\DeepSliceResults.csv.

4

Generate a PDF report

Choose the PDF Contents (Summary Stats, Linearity Plot, Sample Images, Angle Metrics), optionally click Preview Report, then Generate Report (PDF). The file is <base>_report.pdf in the output directory. It needs the reportlab package (pip install reportlab).

5

Open directly in QuickNII

Optionally enter the QuickNII executable via Browse (or set a default in Preferences), export as JSON first, then click Open in QuickNII.

✓ Outcome

You exported reproducible outputs for both computational and visual QC workflows.

Intermediate

Lesson 9 - Session & QuickNII Roundtrip

1

Save state during long work

Click Save Session (Ctrl+S) and choose a name; the file ends in .deepslice-session.json. It stores images, options, predictions, curation and anchors. A dot in the Session: label and a * in the window title mean unsaved changes.

2

Load previous sessions

Click Load Session / QuickNII (Ctrl+O) > Browse... and pick a .deepslice-session.json to continue where you left off. The same menu lists up to five Recent sessions.

3

Load QuickNII JSON/XML for re-curation

Pick an existing QuickNII .json or .xml with the same dialog. Species and markers are preserved when available.

4

Start fresh

New Session (Ctrl+N) resets the workspace; if you have unsaved changes you are asked first. Closing the window asks the same question.

✓ Outcome

You can pause/resume curation and roundtrip external QuickNII outputs without losing context.

Lesson 10 - Diagnostics, Error Reports, and Auto-Fix

This app includes structured logging and guided remediation for common runtime issues. All three tools live in the top bar's Errors menu.

Open Error Log

Opens the persistent log file for full traceback and runtime details.

Copy Last Error

Copies a complete report payload with context, traceback, and analysis. Greyed out until an error has occurred.

Try Auto-Fix Last Error

Runs safe automated fixes for known patterns such as a missing Python package.

Error Dialog Buttons

Use Copy Error Report to share diagnostics; use Try Auto-Fix when it is offered.

Recommended response sequence

  1. Read the dialog context and analysis summary.
  2. Click Try Auto-Fix if offered.
  3. If still failing, click Copy Error Report and share that payload.
  4. Open the log file to inspect the full traceback chronology.
Preferences (Ctrl+,) lets you set the default species for new sessions, theme, default output directory, default QuickNII path and whether the runtime console is shown by default.

✓ Outcome

Errors become actionable quickly, with machine-readable details suitable for AI-assisted repair.

Troubleshooting

ProblemResolution
ModuleNotFoundError: No module named 'tensorflow'Activate the project venv and re-run python -m pip install -e . (it installs the supported TensorFlow version), or use Errors > Try Auto-Fix Last Error.
ModuleNotFoundError: No module named 'skimage'Run python -m pip install scikit-image in the same activated venv (or re-run the project install).
deepslice-gui is not foundThe venv is not active or the install step failed. Activate it, or start with python -m DeepSlice.gui.app.
Run Alignment disabledRead the orange line under the button and the Validation: text in Settings. Common causes: no images, fewer than 2 sections, duplicate or unreadable section numbers, non-coronal cutting plane, ensemble and secondary-only both ticked, or manual thickness of zero.

Hardware Health shows CPU onlyExpected on many native Windows TensorFlow setups. CPU mode is supported.
Generate Report (PDF) failsInstall the extra: python -m pip install reportlab.
QuickNII launch failsSet a valid QuickNII executable path in the Export panel and make sure a JSON export exists.
Atlas preview unavailableInstall nibabel (python -m pip install nibabel), then check the runtime log for atlas download issues and verify network/path permissions.
Prediction failed dialog appearsUse Copy Error Report and share the full payload; run Try Auto-Fix if available.

Next Steps

Production Template

Agree a standard profile for your lab: species, section-number policy, thickness, quality-gate settings and export defaults (set in Preferences).

QC Discipline

Adopt a fixed curation sequence: Detect Outliers -> Apply Bad Section Flags -> Normalize Angles -> Enforce Index Order -> Enforce Index Spacing.

Operational Completion Checklist

  • App launches and Hardware Health executes successfully
  • Dataset ingested with every row showing Status "OK"
  • Configuration validated; input quality gate findings reviewed; Run Alignment completes
  • Curation applied with at least one quality-control pass
  • JSON export + CSV sidecar generated
  • PDF report generated for documentation
  • Session saved for reproducibility
  • Error workflow tested: Copy Last Error and Open Error Log
